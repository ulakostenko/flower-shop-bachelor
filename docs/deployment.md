# 📄 Інструкція для Release Engineer

## Інструкція з розгортання проєкту у production-середовищі

---

## 1. Вимоги до апаратного забезпечення

| Компонент           | Параметри                        |
|---------------------|----------------------------------|
| Операційна система  | Windows 10/11 або Linux (Ubuntu) |
| Архітектура системи | x64                              |
| CPU                 | 2+ ядра                          |
| RAM                 | 2 GB+                            |
| Диск                | 2 GB+                            |

---

## 2. Необхідне програмне забезпечення

| ПЗ                       | Призначення                 |
|--------------------------|-----------------------------|
| OSPanel                  | Локальний веб-сервер        |
| PHP                      | Версія 8.1+                 |
| MySQL                    | Версія 5.7+                 |
| PhpMyAdmin               | Управління базою даних      |
| IntelliJ IDEA / PhpStorm | Розробка PHP-коду           |
| Git                      | Клонування репозиторію      |
| Composer (опціонально)   | Управління залежностями PHP |

---

## 3. Налаштування мережі

- Локальний сервер запускається на `localhost`.
- Стандартний порт веб-сервера: `80`.
- Доступ до PhpMyAdmin за адресою:  
  `http://localhost/phpmyadmin`

---

## 4. Налаштування OSPanel

1. Встановіть OSPanel з офіційного сайту:  
   [https://ospanel.io/](https://ospanel.io/)

2. Створіть нову директорію для сайту:  
   `…\OSPanel\domains\FlowersStore\`

3. Розархівуйте файли WordPress-сайту у вказану теку.

---

## 5. Налаштування СУБД (MySQL)

1. Запустіть OSPanel та відкрийте PhpMyAdmin.

2. Створіть нову базу даних:  
   `flower_shop_db`

3. Імпортуйте підготовлений файл бази даних:  
   `flower_shop_db.sql`

---

## 6. Розгортання коду

1. Завантажте архів сайту WordPress з шаблоном.

2. Розпакуйте архів у директорію:  
   `…\OSPanel\domains\FlowersStore\`

3. Клонувати репозиторій кастомного плагіна:

```bash
git clone https://github.com/ulakostenko/flower-shop-bachelor.git
```

4. Скопіюйте теку плагіна у директорію WordPress:
   `wp-content/plugins/flower-custom-functions/`

5. Активуйте плагін у адмін-панелі WordPress.

6. Відредагуйте файл `wp-config.php`:

```bash
define('DB_NAME', 'flower_shop_db');
define('DB_USER', 'root');
define('DB_PASSWORD', '');
define('DB_HOST', 'localhost');`
```

## 7. Перевірка працездатності

Сайт вважається розгорнутим успішно, якщо:

* Домашня сторінка доступна за адресою:
  http://flowersstore:8080/
* Адмін-панель доступна за адресою:
  http://flowersstore:8080/wp-admin/
* Кастомний плагін активний у списку плагінів.
* Працює функціонал:
    * SVG-таймер акцій.
    * Автоматична знижка при купівлі 3+ букетів.
